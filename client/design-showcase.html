架构设计亮点

六大核心设计，贯穿业务、安全、性能、可扩展性

🛡

统一网关深度防御

// defense-in-depth

7 过滤器链顺序执行：Auth/JWT 鉴权 → CSRF 防护 → 灰度路由 → HTTPS 强制 → Redis Lua 限流 → 请求日志 → XSS 拦截。

Auth→CSRF→灰度→HTTPS→限流→日志→XSS
Resilience4j 熔断Token 黑名单Redis Lua 原子化CORS 热更新
🔧

策略模式多场景复用

// strategy-pattern

支付服务（支付宝 / 微信）与营销服务（满减 / 直降）均采用策略 + 工厂模式，新增渠道只需实现接口，完全遵循开闭原则。

支付策略 PaymentStrategy AlipayStrategyImpl WechatPayStrategyImpl
营销策略 DiscountStrategy DirectDiscountStrategy FullReductionStrategy
🔐

RBAC 权限模型

// access-control

admin 服务独立五表设计，与 C 端完全物理隔离。独立 JWT 密钥、独立 ThreadLocal 上下文、独立鉴权拦截器，权限标识精确到按钮级。

BCrypt 密码动态路由AOP 操作日志admin:模块:操作
🔒

库存乐观锁防超卖

// optimistic-lock

独立库存表 + version 字段 + 自定义 SQL（WHERE version = #{version}），配合重试机制（最多 3 次，间隔 50ms），在高并发下保证数据一致性。

UPDATE stock SET available = available - #{qty},
       version = version + 1
WHERE sku_id = #{skuId}
  AND version = #{version}
  AND available >= #{qty}
🔄

AOP 幂等切面

// idempotency

自定义 @PayIdempotent / @Idempotent 注解 + 环绕切面，基于 Redis 分布式锁实现支付和营销操作的防重复提交。

@PayIdempotent(key = "#dto.orderNo", timeout = 30)
public PayVO createPay(CreatePayDTO dto) {
    // 切面自动：加锁 → 执行业务 → 释放锁
}
📤

RocketMQ 异步解耦

// event-driven

订单状态变更通过 RocketMQ 发布事件，消息服务异步监听从站内通知、短信、邮件；营销服务监听营销事件批量推送。削峰填谷，服务间松耦合。

Order 服务 → RocketMQ → Message 服务 → 通知 / 短信 / 邮件

自动化部署架构

从源码到上线，一行命令完成全流程自动化

①

一行命令启动

bash scripts/docker-prod.sh — 克隆仓库后一条命令完成全部部署，14 个容器自动编排启动。

②

智能变更检测

通过对比子模块 commit hash 自动识别变更服务。common 模块变更触发全量重建，单个服务变更仅重建该服务。

③

分批并行构建

默认每批 2 个服务并行构建，带 spinner 动画进度 UI + 实时日志预览。可通过 BUILD_PARALLEL_NUM 环境变量调节并发数。

④

自动密钥生成

首次部署自动检测 CHANGE_ME 占位符，通过 openssl rand -base64 生成 8 个随机密钥，替换所有敏感配置项。

⑤

Nacos 配置自动导入

13 个 Data ID（路由/限流/灰度/CORS + 9 个服务配置）通过 nacos-init.sh 批量导入，支持鉴权/非鉴权模式自适应。

⑥

健康检查全覆盖

所有服务均配置 Docker healthcheck，启动顺序按依赖链严格编排：基础设施 → Nacos → 业务服务 → 网关 → 前端。

发布流程设计

Git 子模块独立演进 + Docker Compose 统一编排 + 增量发布

💻

日常开发

子模块分支→独立提交→PR 审查→更新指针

每个微服务独立 Git 仓库，独立分支、独立版本，根仓库通过 commit 指针精确锁定各模块版本。

🚀

一键部署

git clone→子模块初始化→Docker 构建→14 容器上线

新环境从零到上线仅需一条命令。脚本自动完成子模块拉取、镜像构建、容器编排、配置导入全流程。

🔄

增量更新

代码推送→检测变更→增量构建→滚动重启

docker-prod.sh update 自动识别变更模块，仅重建受影响的服务镜像，其余容器不受影响。

⚡

GitHub Actions 每日自动同步所有子模块到 main 分支，确保各仓库版本一致性。

🔒 端口隔离

生产环境仅 frontend(:80) 和 gateway(:8181) 对外暴露，8 个业务服务端口绑定容器内部网络，外网无法直接访问。

🔑 密钥分离

admin 后台与 C 端 user 使用独立 JWT 密钥（JWT_SECRET / ADMIN_JWT_SECRET），一方泄露不影响另一方。

🔒 防误部署

脚本自动检测 CHANGE_ME 占位符，拒绝使用未修改的安全模板部署，强制用户生成真实密钥。

💻 最小权限

Docker 容器以非 root 用户（USER app）运行。Nacos 生产环境绑定 127.0.0.1 仅本地访问。
